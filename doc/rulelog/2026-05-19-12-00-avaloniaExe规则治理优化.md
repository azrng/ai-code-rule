### `avaloniaExe`

#### 修改原因
- 根据 AI 系统架构视角评审和 Claude Code 工具审查反馈，提升 Avalonia 桌面端规则模板的可执行性、跨 Agent 协作清晰度和 token 使用效率。

#### 主要修改内容
1. 统一 UI 规则读取顺序，明确 `AGENTS.md` 优先级高于 `design-system.yaml` 的读取建议。
2. 将阶段职责从具体工具名解耦为视图实现角色、业务实现角色和协作联调角色。
3. 在根规则中补充理解检查清单、查证优先级、技术债务与重构判断、纠错与回退机制。
4. 子规则标题改为语义化标题，减少 cross-reference 歧义。
5. 将重复的技术债务评估框架上收到根规则，子规则改为引用。
6. 补充 DTO 契约回退规则、本地数据安全规则和跨 Agent / 跨会话交接字段要求。
7. 将任务归档 SOP 从 `TASK.md` 迁移到 `doc-AGENTS.md`，保持 `TASK.md` 以任务数据为主。
8. 统一 devlog 命名建议为 `YYYY-MM-DD-HHmmss-中文任务简述.md`，保留秒级时间并减少文件名分隔段。
