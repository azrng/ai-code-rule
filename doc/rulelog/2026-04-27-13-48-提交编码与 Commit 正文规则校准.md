### `avaloniaExe`

#### 修改时间
- 2026-04-27 13:48

#### 修改原因
- Windows / PowerShell 场景下中文 Git 提交信息存在通过标准输入管道传递后被写成 `?` 的风险，需要在模板规则中明确规避方式。
- 原 `Commit 规范` 将过程性验证说明与真实风险混在同一字段中，容易导致提交正文中的 `风险` 字段含义不清。
- “等价验证”的未覆盖内容原要求写入 Commit 正文，与当前希望 Commit 正文只保留真实风险和交付摘要的口径不一致。

#### 主要修改内容
- 在 `avaloniaExe/AGENTS.md` 的编码规则中补充中文 Git 提交信息处理方式：优先使用 `git commit -m`、多个 `-m` 参数，或使用 `UTF-8` 编码文件配合 `git commit -F <file>`。
- 明确禁止通过标准输入管道直接传递中文提交信息，包括 `git commit -F -`、here-string 管道等方式。
- 在 `Commit 规范` 中补充提交前 UTF-8 与最近一次提交信息回读要求，降低中文提交乱码风险。
- 调整 Commit 正文字段要求，移除固定 `验证` 字段，并明确 `风险` 仅记录真实的代码、业务、数据、兼容性、部署或发布风险。
- 明确未执行人工测试、未补 smoke test、未覆盖某项校验、仅做等价验证等过程性说明，应写在最终输出与 `doc/devlog/`，不写入 Commit 正文。
- 调整“提交前最小回归”中等价验证的记录要求，改为在最终说明与 `doc/devlog/` 中写清执行内容、未覆盖校验和后续建议。
- 同步更新 `avaloniaExe/AGENTS.md` YAML front matter：`version` 从 `1.2.0` 更新为 `1.2.2`，`last_updated` 更新为 `2026-04-27`。
