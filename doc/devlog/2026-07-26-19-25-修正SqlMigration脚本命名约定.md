# 修正 SqlMigration 脚本命名约定

## 本次目标
- 按用户纠正与库源码，把迁移脚本命名从错误的 `版本号_描述.sql` 修正为 `版本号.sql` / `版本号.txt`（如 `1.0.0.sql`、`1.1.0.txt`）。

## 根因
- `Azrng.SqlMigration` 解析规则（`SqlMigrationService.cs`）：文件名去掉 `VersionPrefix` 与扩展名（`.sql` / `.txt`）后的剩余部分**整体作为版本号**，带描述文字（如 `1.1.0_add_user_phone`）会破坏版本解析与排序。README 官方示例为 `1.0.0.sql`、`1.1.0.txt`、`1.0.0.1.sql`。
- 错误写法源自 `skills/azrng-efcore` 技能文档，本日多轮修复将其扩散到 6 个模板目录。

## 核心改动
- 6 个模板目录的迁移规则与目录职责表全部改为 `版本号.sql` / `版本号.txt` 命名，并注明「不含描述文字，剩余部分会被整体解析为版本号」：dotnetLayered、dotnetCoreSingle、dotnetBlazor、reactLinkdotNet、reactLinkdotNet-ai、vueLinkdotNet。
- 修正错误源头：仓库内 `skills/azrng-efcore/SKILL.md` 与用户技能目录 `~/.claude/skills/azrng-efcore/SKILL.md` 同步修正（后者不在本仓库版本控制内）。

- `dotnetCoreSingle/backend-AGENTS.md`（2.0.1）

## 校验情况
- 命名规则对照 `nuget-packages` 中 `Azrng.SqlMigration` 源码与 README 官方示例核实。
- 全仓库与用户技能目录检索 `版本号_描述` / `add_user_phone` / `_init` / `描述.sql`：零命中。
