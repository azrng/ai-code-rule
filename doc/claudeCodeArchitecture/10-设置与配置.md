# 10 - 设置与配置

## 双配置系统

Claude Code 有两套独立的配置系统：

### 1. GlobalConfig（`~/.claude.json`）

项目级状态、用户偏好、feature flags、缓存：

```typescript
// src/utils/config.ts
function getGlobalConfig(): GlobalConfig
function saveGlobalConfig(config: GlobalConfig): void
```

- 使用 `lockfile` 保证多进程安全
- 写入时更新缓存
- 后台 `fs.watchFile` 检测外部修改

### 2. Settings（`settings.json`）

权限规则、hooks、sandbox 配置等：

```json
// ~/.claude/settings.json (用户级)
// .claude/settings.json (项目级)
// .claude/settings.local.json (本地级)
{
  "permissions": {
    "allow": ["Bash(npm test)", "Read"],
    "deny": ["Bash(rm -rf *)"],
    "ask": ["Write"]
  },
  "hooks": { ... },
  "mcpServers": { ... },
  "defaultMode": "default",
  "model": "sonnet"
}
```

## Settings 合并优先级

```
pluginSettings < userSettings < projectSettings < localSettings < policySettings < flagSettings
```

| 来源 | 路径 | 说明 |
|------|------|------|
| `userSettings` | `~/.claude/settings.json` | 用户全局设置 |
| `projectSettings` | `.claude/settings.json` | 项目设置（提交到 Git） |
| `localSettings` | `.claude/settings.local.json` | 本地设置（不提交） |
| `policySettings` | MDM/plist/HKCU | 组织策略 |
| `flagSettings` | GrowthBook | 远程 feature flags |

### Policy Settings 级联

```
remote > MDM/plist > file > HKCU
```

### Zod 校验

所有 settings 通过 `SettingsSchema`（Zod）校验，无效配置会报告错误：

```typescript
const settingsResult = SettingsSchema.safeParse(rawSettings)
if (!settingsResult.success) {
  // 报告校验错误，使用默认值
}
```

### 缓存策略

- 每个来源独立缓存（`setCachedSettingsForSource`）
- 会话级别缓存（`getSettingsWithErrors`）
- 写入时通过 `resetSettingsCache()` 失效

## CLAUDE.md 系统

CLAUDE.md 是项目级的上下文文件，自动注入系统提示词：

```
项目根目录/CLAUDE.md          — 项目级指令
~/.claude/CLAUDE.md           — 用户全局指令
.claude/CLAUDE.md             — 项目级（同上）
.claude/settings.local.json   — 本地设置
```

加载逻辑在 `src/constants/prompts.ts` 的 `getSystemPrompt()` 中。

## 模型选择（`src/utils/model/model.ts`）

```typescript
type ModelSetting = ModelName | ModelAlias | null

// 模型解析优先级
function getMainLoopModel(): ModelName {
  const model = getUserSpecifiedModelSetting()  // 用户指定
  if (model) return parseUserSpecifiedModel(model)
  return getDefaultMainLoopModel()              // 默认模型
}

// 模型别名
type ModelAlias = 'opus' | 'sonnet' | 'haiku' | 'best' | 'opusplan'

function parseUserSpecifiedModel(input): ModelName {
  // 'opus' → getDefaultOpusModel()
  // 'sonnet' → getDefaultSonnetModel()
  // 'haiku' → getDefaultHaikuModel()
  // 'best' → getBestModel()
  // 'opusplan' → Sonnet 默认，Opus 用于 plan 模式
}
```

### 模型来源

1. CLI 参数 `--model`
2. 环境变量 `ANTHROPIC_MODEL`
3. Settings `settings.json` 中的 `model`
4. GrowthBook feature flags
5. 默认值

## Feature Flags（GrowthBook）

```typescript
// src/services/analytics/growthbook.ts
async function initializeGrowthBook(): Promise<void>
function getFeatureValue_CACHED_MAY_BE_STALE<T>(key: string, fallback: T): T

// 编译时 feature flags
import { feature } from 'bun:bundle'
if (feature('COORDINATOR_MODE')) { ... }
```

两种 flag 机制：
1. **编译时**：`feature()` 宏，构建时 dead code elimination
2. **运行时**：GrowthBook，支持远程动态配置
