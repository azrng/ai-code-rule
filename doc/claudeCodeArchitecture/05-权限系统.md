# 05 - 权限系统

## 权限模式（PermissionMode）

定义在 `src/types/permissions.ts`：

```typescript
// 外部可配置的模式
type ExternalPermissionMode =
  | 'acceptEdits'        // 自动接受编辑，其他需确认
  | 'bypassPermissions'  // 跳过所有权限检查
  | 'default'            // 默认模式，逐个确认
  | 'dontAsk'            // 不询问，自动拒绝未授权操作
  | 'plan'               // 计划模式，只读操作

// 内部模式（包含外部模式）
type InternalPermissionMode =
  | ExternalPermissionMode
  | 'auto'               // 自动模式（classifier 驱动）
  | 'bubble'             // 冒泡模式（子代理权限上报）
```

## 权限规则体系

### 规则结构

```typescript
type PermissionRule = {
  source: PermissionRuleSource       // 规则来源
  ruleBehavior: PermissionBehavior   // allow | deny | ask
  ruleValue: {
    toolName: string                 // 工具名
    ruleContent?: string             // 匹配内容（如命令模式）
  }
}
```

### 规则来源（优先级从低到高）

```
pluginSettings < userSettings < projectSettings < localSettings < policySettings < flagSettings < session
```

| 来源 | 配置文件 | 说明 |
|------|---------|------|
| `userSettings` | `~/.claude/settings.json` | 用户全局设置 |
| `projectSettings` | `.claude/settings.json` | 项目级设置（提交到 Git） |
| `localSettings` | `.claude/settings.local.json` | 本地项目设置（不提交） |
| `policySettings` | 组织策略（MDM/plist/HKCU） | 企业管理策略 |
| `flagSettings` | GrowthBook flags | 远程 feature flags |
| `cliArg` | `--permission-mode` | CLI 参数 |
| `session` | 运行时 | 会话内临时规则 |

### 规则类型

```typescript
type PermissionUpdate =
  | { type: 'addRules', destination, rules, behavior }
  | { type: 'replaceRules', destination, rules, behavior }
  | { type: 'removeRules', destination, rules, behavior }
  | { type: 'setMode', destination, mode }
  | { type: 'addDirectories', destination, directories }
  | { type: 'removeDirectories', destination, directories }
```

## 权限决策流程

```
工具调用 → checkPermissions()
  ├── 查找 alwaysDenyRules → 匹配则 deny
  ├── 查找 alwaysAllowRules → 匹配则 allow
  ├── 查找 alwaysAskRules → 匹配则 ask
  ├── 检查 PermissionMode
  │   ├── 'bypassPermissions' → allow
  │   ├── 'dontAsk' → deny
  │   ├── 'acceptEdits' → 编辑类工具 allow，其他 ask
  │   ├── 'plan' → 只读工具 allow，写入工具 deny
  │   ├── 'auto' → classifier 判定
  │   └── 'default' → ask
  └── 返回 PermissionDecision
```

### PermissionResult 类型

```typescript
type PermissionResult =
  | PermissionAllowDecision    // 允许执行
  | PermissionAskDecision      // 需要用户确认
  | PermissionDenyDecision     // 拒绝执行
  | { behavior: 'passthrough', ... }  // 传递给下一个检查器
```

### PermissionDecisionReason

```typescript
type PermissionDecisionReason =
  | { type: 'rule', rule: PermissionRule }    // 由规则决定
  | { type: 'mode', mode: PermissionMode }    // 由模式决定
  | { type: 'classifier' }                    // 由 classifier 决定
  | { type: 'hook' }                          // 由 hook 决定
  | { type: 'default' }                       // 默认行为
```

## ToolPermissionContext

工具执行时的权限上下文（`src/Tool.ts`）：

```typescript
type ToolPermissionContext = DeepImmutable<{
  mode: PermissionMode
  additionalWorkingDirectories: Map<string, AdditionalWorkingDirectory>
  alwaysAllowRules: ToolPermissionRulesBySource
  alwaysDenyRules: ToolPermissionRulesBySource
  alwaysAskRules: ToolPermissionRulesBySource
  isBypassPermissionsModeAvailable: boolean
  isAutoModeAvailable?: boolean
  strippedDangerousRules?: ToolPermissionRulesBySource
  shouldAvoidPermissionPrompts?: boolean   // 后台 agent 自动拒绝
  awaitAutomatedChecksBeforeDialog?: boolean  // coordinator 模式
  prePlanMode?: PermissionMode  // 进入 plan 模式前的模式
}>
```

## Yolo Classifier

在 `auto` 模式下，使用 classifier 自动判断工具调用是否安全：

```typescript
// src/utils/permissions/yoloClassifier.ts
async function classifyYoloAction(
  tool, input, transcript, context
): Promise<'allow' | 'ask'>
```

- 构建工具调用的上下文（`buildTranscriptForClassifier`）
- 使用小模型（Haiku）快速分类
- 结果异步返回，可与用户确认并行（`pendingClassifierCheck`）

## 权限更新持久化

权限变更可通过 `applyPermissionUpdates()` 持久化到不同目标：

```typescript
async function persistPermissionUpdates(
  updates: PermissionUpdate[],
  destination: PermissionUpdateDestination,
): Promise<void>
```

- `userSettings` → `~/.claude/settings.json`
- `projectSettings` → `.claude/settings.json`
- `localSettings` → `.claude/settings.local.json`
- `session` → 仅内存
- `cliArg` → 不持久化
