# 02 - 启动与生命周期

## 启动流程概览

```
CLI 入口 → 快速路径分发 → 完整初始化 → REPL 循环 → 退出清理
```

## 阶段 1：CLI 入口（`src/entrypoints/cli.tsx`）

```typescript
async function main(): Promise<void> {
  const args = process.argv.slice(2);

  // 1. 极速路径：--version 零模块加载
  if (args[0] === '--version') {
    console.log(`${MACRO.VERSION} (Claude Code)`);
    return;
  }

  // 2. 快速路径分发（均使用动态 import）
  //    --dump-system-prompt → 导出系统提示词
  //    --claude-in-chrome-mcp → Chrome MCP server
  //    --chrome-native-host → Chrome 原生宿主
  //    --daemon-worker → 守护进程 worker
  //    remote-control → Bridge 模式
  //    mcp → MCP server 模式
  //    其他 → 走完整 main() 流程
}
```

**设计要点**：所有导入都是动态的（`await import()`），最小化模块加载开销。快速路径不触发完整初始化。

## 阶段 2：完整初始化（`src/main.tsx` → `main()`）

```
main()
  ├── 安全设置（NoDefaultCurrentDirectoryInExePath）
  ├── 信号处理（SIGINT, exit）
  ├── URL scheme 处理（cc:// 协议）
  ├── CLI 参数解析
  ├── enableConfigs() — 启用配置系统
  ├── 认证（OAuth / API Key）
  ├── GrowthBook 初始化（feature flags）
  ├── 模型选择与验证
  ├── 权限模式初始化
  ├── MCP 服务器连接
  ├── 工具池组装
  ├── 系统提示词构建
  └── run() — 启动 REPL 或 print 模式
```

## 阶段 3：会话状态机

会话有三种状态（`src/utils/sessionState.ts`）：

```
idle ──────────────► running ──────────────► idle
  │                      │                      │
  │                      ▼                      │
  │              requires_action                 │
  │              (等待用户输入)                    │
  │                      │                      │
  └──────────────────────┴──────────────────────┘
```

- **idle**：空闲，等待用户输入
- **running**：正在执行（API 调用 / 工具执行）
- **requires_action**：需要用户操作（权限确认、工具问题等）

状态变化通过 `notifySessionStateChanged()` 广播，支持监听器模式：

```typescript
setSessionStateChangedListener(cb: (state, details?) => void)
```

## 阶段 4：主循环（REPL）

```
用户输入
  → processUserInput()
    → 构建 UserMessage
    → QueryEngine.submitMessage()
      → fetchSystemPromptParts()  // 系统提示词
      → queryModelWithStreaming()  // API 调用
      → StreamingToolExecutor      // 流式工具执行
        → addTool() → processQueue()
        → 权限检查 → 执行 → 结果
      → 追加 tool_result 到消息
    → 检查终止条件（maxTurns, maxBudget, 用户中断）
    → 下一轮或回到 idle
```

## 阶段 5：自动压缩（Compaction）

当消息接近上下文窗口限制时：

```
消息历史 → streamCompactSummary() → 摘要替换旧消息
                                   → 插入 compact boundary
```

`getMessagesAfterCompactBoundary()` 只取 boundary 之后的消息发送给 API。

## 快速路径对比

| 路径 | 入口 | 初始化范围 | 用途 |
|------|------|-----------|------|
| `--version` | cli.tsx | 无 | 版本查询 |
| `-p "prompt"` | print.ts | 最小 | 单次执行 |
| `mcp` | mcp.ts | MCP 相关 | MCP server |
| `remote-control` | bridgeMain.ts | Bridge 相关 | 远程控制 |
| 默认 | main.tsx | 完整 | 交互式 REPL |
