# 11 - UI 组件架构

## 渲染引擎概述

Claude Code 使用自定义的 React Ink 变体作为终端 UI 框架。核心渲染流水线：

```
React 组件树 → Yoga 布局 → Screen 缓冲区 → Diff 引擎 → ANSI 输出
```

### 4. Screen 缓冲区（`src/ink/screen.ts`）

```typescript
class Screen {
  cells64: BigInt64Array      // 64-bit 编码的单元格数据
  stylePool: StylePool        // 样式池（ID 化减少内存）
  hyperlinkPool: Pool<Hyperlink>  // 超链接池
  damage: Rectangle | null    // 脏区域标记

  // 样式转换缓存
  transition(fromId: number, toId: number): string
}
```

**单元格 64-bit 编码**：每个单元格用一个 `BigInt64` 编码字符、样式 ID、宽度等信息，实现紧凑存储和快速比较。

### 5. 滚动优化（`shiftRows`）

```typescript
function shiftRows(screen: Screen, top: number, bottom: number, n: number): void
```

- 使用 `copyWithin` 实现内存级别的行移动
- 支持 SU（Scroll Up）和 SD（Scroll Down）
- 配合 DECSTBM（Set Top and Bottom Margins）实现硬件加速滚动

## 组件设计模式

### 1. Provider 模式

所有全局状态通过 React Context 传递，避免 prop drilling。

### 2. 错误边界

```typescript
static getDerivedStateFromError(error: Error) {
  return { error }
}
componentDidCatch(error: Error) {
  this.handleExit(error)
}
```

### 3. 引用计数 Raw Mode

多个组件可能同时需要 raw mode，通过引用计数避免过早退出：

```typescript
handleSetRawMode = (isEnabled: boolean): void => {
  this.rawModeEnabledCount += isEnabled ? 1 : -1
  if (this.rawModeEnabledCount === 0) {
    this.props.stdin.setRawMode(false)
  } else if (isEnabled) {
    this.props.stdin.setRawMode(true)
  }
}
```

### 4. 虚拟化渲染

- **Screen 双缓冲**：frontFrame / backFrame 交替使用
- **脏区域标记**：damage rectangle 限制 diff 范围
- **样式池化**：StylePool 减少样式对象分配
- **字符缓存**：charCache 持久化 tokenize 结果

## 关键性能优化

| 优化 | 说明 |
|------|------|
| DECSTBM 硬件滚动 | 终端原生滚动命令代替全量重写 |
| 双缓冲 Screen | 前后帧交替，避免撕裂 |
| 脏区域 diff | 只渲染 damage rectangle 内的变化 |
| 样式池 | 样式 ID 化，减少 ANSI 转义序列 |
| 字符缓存 | 复用 tokenize 结果 |
| 同步 resize | 避免 debounce 导致的闪烁 |
| BSU/ESU 原子更新 | Begin/End Synchronized Update 包裹关键渲染 |
