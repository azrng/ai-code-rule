# 01 - Claude Code 项目总览

## 项目简介

Claude Code 是 Anthropic 官方的 CLI 交互式编程助手，支持 CLI、桌面应用、Web 应用和 IDE 扩展（VS Code / JetBrains）等多种运行形态。

## 技术栈

| 层面 | 技术选型 |
|------|----------|
| 语言 | TypeScript（主体）+ TSX（UI 组件） |
| 运行时 | Node.js 18+ / Bun |
| 构建 | Bun bundler + 宏替换（`feature()`, `MACRO.*`） |
| TUI 框架 | React Ink（终端 UI 渲染） |
| API 客户端 | `@anthropic-ai/sdk`（Anthropic 官方 SDK） |
| Schema 校验 | Zod v4 |
| 本地存储 | JSON 文件（`~/.claude.json` + `settings.json`） |
| 测试 | Jest / Vitest |
| 包管理 | npm |

## 顶层目录结构

```
src/
├── entrypoints/        # 入口点（CLI、MCP server、SDK）
├── bootstrap/          # 全局状态初始化
├── cli/                # CLI 层（print、transport、IO）
├── components/         # React Ink UI 组件
├── commands/           # 斜杠命令（/help, /config 等 80+ 个）
├── constants/          # 常量定义（prompts、tools、figures）
├── context/            # React Context providers
├── hooks/              # React Hooks + 工具权限 hooks
├── services/           # 核心服务（API、MCP、analytics）
├── tools/              # 内置工具实现（Bash、Edit、Read 等）
├── skills/             # 技能系统（bundled + 目录技能）
├── bridge/             # 远程控制（Bridge/CCR）模块
├── coordinator/        # 协调器模式
├── buddy/              # 伴侣精灵（Companion）
├── types/              # 核心类型定义
├── utils/              # 工具函数（权限、配置、消息等）
├── Tool.ts             # Tool 接口定义
├── tools.ts            # 工具注册与组装
├── main.tsx            # 主入口函数
├── state/              # AppState 定义
└── types/              # 类型定义
```

## 核心文件速查

| 文件 | 职责 |
|------|------|
| `src/entrypoints/cli.tsx` | CLI 最入口，分发快速路径 |

## 构建与运行

```bash
# 开发
npm run dev          # 带热重载的开发模式
npm run build        # 生产构建

# 启动
claude               # 交互式 REPL
claude -p "prompt"   # 单次执行（print mode）
claude --resume      # 恢复上次会话
```

## 多形态支持

同一个代码库通过入口分发支持多种形态：

- **CLI REPL**：`src/entrypoints/cli.tsx` → `src/main.tsx` → React Ink TUI
- **Print 模式**（`-p`）：`src/cli/print.ts` → 无 TUI 的流式输出
- **MCP Server**：`src/entrypoints/mcp.ts` → 作为 MCP server 运行
- **SDK**：`src/entrypoints/sdk/` → 作为库嵌入其他应用
- **Bridge**：`src/bridge/` → 远程控制模式（本地 ↔ 云端）
