# 规则退役清单

本清单用于判断 AI Rule 中哪些内容可以随着模型能力提升而压缩或退役。它不把“模型通常会这么做”直接等同于“规则没有价值”：架构事实、接口契约、数据兼容、权限边界、安全底线和用户偏好不因模型变强而自动删除。

## 判定口径

- 先区分“事实 / 决策 / 权限”与“模型行为补丁”。前者保留，后者才进入退役候选。
- 只有在同一规则覆盖至少 5 个同类任务、连续出现“冗余”反馈，且没有冲突或违反反馈时，才允许进入退役评审。
- 退役优先采用“展开清单压缩为一句原则”，连续一个版本周期没有新增违反或冲突后再删除；删除前补等价的验证或承接说明。
- 规则被加载但未触发，不等于冗余；“冗余”必须说明它没有改变决策、实现或验证结果。

每次规则版本变更时，维护者只审查本表中有新增证据的条目，不对全部规则做无证据清理。

## 常驻规则预算

根 `AGENTS.md` 的预算只统计固定行为规则段（根文件原则、全局工作规则、编码硬约束、触发式协作规则），不统计目标清单、子规则索引、阶段变量和能力导航等动态内容。新增常驻规则前，必须优先合并重复口径、下沉按需细则或退役已有行为补丁；测试对固定段设置上限，避免“每次只加一行”持续膨胀。
