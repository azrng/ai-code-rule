01 / STARTUP PIPELINE

启动序列

从进程拉起到进入命令行或交互模式，共五步。任何一步失败都会进入异常兜底： stderr 输出「错误：{消息}」与详细信息，stdin 非重定向时提示「按 Enter 键退出。」，退出码 1。

设置编码

stdout / stdin 切 UTF-8；个别宿主没有标准输入句柄时 setter 会抛，直接落入异常兜底。

解析内容包

PackResolver 决定资源来源：--pack / --offline / 更新检查，共七种情况，见 02。

装配 Store

把解析结果包成 IResourceProvider，喂给 ResourceStore 与 SkillsStore；内嵌资源是永久兜底。

加载 manifest

ManifestLoader.Load 读入 manifest 并校验；banner 打印 pack 版本（版本以 manifest.vars 为唯一事实源）。

分发

带参数走命令行模式（--check / --detect / --plan / --recipe / --upgrade / --emit / --help）； 无参数进入交互向导。

02 / PACK RESOLUTION

内容包解析的七种情况 新增

exe 启动后第一件真正的事：确定「规则与技能内容从哪来」。本地缓存位于 %LOCALAPPDATA%\RuleAssembler\Packs\，更新检查拉 Release 的 latest.json（3 秒超时）。内嵌资源永远可用——单 exe 无网络仍能干活。

SC-01 指定包启动 直接生效

--pack 指定内容包

触发 --pack <路径>
  • 跳过一切网络检查，两个 Store 直接挂到指定包
  • 包缺失或损坏硬失败报错退出——显式指定不做静默兜底
use-ai-ruletty
$ use-ai-rule --pack D:\packs\content-2026.10.0.zip
[pack] 使用指定内容包 D:\packs\content-2026.10.0.zip
use-ai-rule 2026.10.0（2026-10-14）
SC-02 离线模式 跳过检查

--offline 离线启动

触发 --offline
  • 不发起任何网络请求
  • 本地缓存命中 → 用缓存；未命中 → 内嵌资源，一行提示说明来源
use-ai-ruletty
$ use-ai-rule --offline
[pack] 离线模式：使用本地缓存 2026.10.0
use-ai-rule 2026.10.0（2026-10-14）

# 缓存未命中时：
[pack] 无本地缓存，使用内嵌资源
SC-03 已是最新 静默通过

更新检查 · 版本相同

触发 latest.json 版本 ≤ 本地版本
  • 拉一次 latest.json，semver 比较后无更新
  • 沿用现有缓存（或内嵌），用户完全无感知
use-ai-ruletty
$ use-ai-rule
[pack] 已是最新：2026.10.0
use-ai-rule 2026.10.0（2026-10-14）
SC-04 发现新版本 询问后生效

更新检查 · 有新版

触发 latest.json 版本更新（选择框 0）
  • 问一次「更新到新版 / 本次跳过」，跳过则本次沿用且不再追问
  • 更新 = 下载两个内容包 → SHA-256 逐文件校验 → 原子落盘后切版本指针
use-ai-ruletty
$ use-ai-rule
[pack] 发现新版本 2026.10.1（当前 2026.10.0）
? 更新到新版 2026.10.1 / 本次跳过
❯ 更新
[pack] 下载 rule-pack.zip … SHA-256 校验通过
[pack] 下载 skills-pack.zip … SHA-256 校验通过
use-ai-rule 2026.10.1（2026-10-14）
SC-05 下载或校验失败 回退兜底

更新下载失败

触发 网络中断 / SHA-256 不匹配
  • 一行告警，绝不阻塞使用
  • 回退现有缓存；无缓存则回退内嵌资源
  • 旧版本指针不动，下次启动重试
use-ai-ruletty
[pack] 告警：更新下载失败（SHA-256 不匹配），
       继续使用 2026.10.0
use-ai-rule 2026.10.0（2026-10-14）
SC-06 包结构不兼容 回退 + 提示升 exe

schema 版本超出支持范围

触发 pack.json schema_version > exe 内置常量
  • 拒绝使用新包（旧 exe + 新包可能解析失败），回退内嵌
  • 明确提示升级 exe——这是「exe 重发条件」的唯一强制场景
use-ai-ruletty
[pack] 内容包 schema 4 高于本程序支持的 3，
       已回退内嵌资源
提示：请升级 use-ai-rule.exe 后再使用新内容包
SC-07 无网络 / 超时 静默降级

更新检查超时

触发 latest.json 3 秒超时 / 网络不可达
  • 不重试、不等待，直接用本地缓存或内嵌
  • 离线环境长期稳定可用，这是一等公民场景而非异常
use-ai-ruletty
[pack] 更新检查超时，使用本地版本 2026.10.0
use-ai-rule 2026.10.0（2026-10-14）
SC-00 汇总 永不不可用

来源解析优先级

顺序决定一切
  • --pack 显式指定（硬失败语义）
  • --offline → 本地缓存 → 内嵌
  • 默认：更新检查 → 缓存/新包 → 内嵌兜底
use-ai-ruletty
1. --pack 指定包        （失败即退出）
2. 本地缓存 Packs\<ver\> （校验通过的历史包）
3. 程序集内嵌资源        （编译期固化，永在）
03 / CLI DISPATCH

命令行分发

带任意参数即进入命令行模式，全部走非交互路径（写入类操作前不再确认）。 「写入」列标注了哪些命令会改动目标目录。

参数作用写入
--check只校验：manifest、片段、全部兼容样例的输出契约一致性、组件问答决策树、内置技能，不写任何文件否
--detect [目录]只做项目检测，打印推荐组合；证据不足时打印待确认维度与候选组合否
--plan 维度=取值…按显式维度解析组合内核，打印命中组件与文件清单；违反钳制或缺组件锚定显式报错否
--recipe <配方.json> [目录]按配方记录重放生成（能力开关按配方重放，design-system 已定制保留），回写配方并补 .gitignore是
--upgrade [目录] [--force]按目标目录配方升级规则；哈希识别本地修改默认保留，--force 全部覆盖并重算哈希是
--emit <目录>把全部兼容样例的组合产物批量输出，用于预览与 emit-baseline 回归比对是
--pack <路径> 新增直接使用指定内容包，跳过更新检查—
--offline 新增跳过网络更新检查，用本地缓存或内嵌资源—
--help打印帮助：模式说明、各参数语义、Skills 导入口径否

06 / SPECIAL PATHS

两条特殊路径

Skills 导入与配方升级各自有一套容易踩坑的分支语义，单独展开。

PATH-A

Skills 导入语义

  • 导入是追加语义：未选中的技能一律不动
  • 覆盖 = 同名技能目录先删后写，按内置内容整体重写，清理上游删改文件造成的残留
  • 跳过 = 保留本地版本，且不记入配方（不进入后续升级同步范围）
  • 交互路径任何一步取消或零勾选 = 整体放弃，配方不记 skills 字段
  • 重放 / 升级路径按配方同步（同名先删后写）；技能或目标已不在当前版本 → 告警跳过，不阻塞规则升级
  • 仅导入模式：不生成规则文件、不写配方；.gitignore 按 minimal 模板幂等追加
  • 技能身份 = 含 SKILL.md 的最外层目录名；分组目录只是维护侧归档
PATH-B

配方升级语义

  • 配方记录生成时的文件 SHA-256（file_hashes），升级时逐文件比对识别本地修改
  • 默认保留修改过的文件，只更新未修改文件；--force 重新纳入写入并按新写入重算哈希
  • 被保留的文件沿用旧哈希回写配方——下次升级仍能持续检测
  • 早期配方无哈希 → 退化为不可检测，明确提示后将按配方直接重放覆盖
  • design-system.yaml 已定制 → 保留本地不覆盖；本地文件疑似旧组合基线时额外告警提示重置
  • 组合已演进（配方组件集在当前 manifest 解不出同一集合）→ 明确报错而非静默错渲
07 / EXIT STATES

结束态

无论走哪条路径，进程只有三种离开方式。

exit 0

完成

规则与技能落盘、配方与 .gitignore 就绪；「仅检测」查看完毕同样以 0 退出。

exit 0

用户取消

任一选择框选「取消 / 跳过」→ 打印「已取消。」，正常退出，不视为错误。

exit 1

异常兜底

未捕获异常：stderr 输出「错误：{消息}」与 InnerException 详细信息；stdin 非重定向时提示「按 Enter 键退出。」后暂留窗口。

写入类路径的固定收尾序列

  1. 写规则文件
  2. Skills 落盘
  3. 写配方 .ai-rule-profile.json
  4. 幂等补 .gitignore
  5. 汇总输出（文件数 / 技能数 / 版本）
