### 浏览器自动化走查
- 界面交付前必须执行浏览器走查：走查用独立实例（独立数据根与端口），不动开发实例的数据与配置；未导入 browser-walkthrough 技能时按最小口径执行——独立实例启动 + 稳态 DOM / computed style 实测判定，瞬态状态与截图拼接伪影不上报为缺陷。
- 组件库迁移、主题或全局样式类任务同属界面交付，交付前走查不可省略：此类任务大量产生「编译通过但视觉静默失效」的问题（选择器优先级不足、类名 / 图标随旧库移除丢失），构建检查无法发现；覆写组件库自带样式前先核对其实际选择器优先级与真实 DOM 结构。
- 操作细节（组件库点击兜底顺序、真实键入路径、rAF 摆位判定）见 browser-walkthrough 技能。
