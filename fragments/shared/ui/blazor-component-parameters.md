- 使用 MudBlazor 组件时，先从 `.csproj` 或 `Directory.Packages.props` 确认锁定版本，再对照该版本组件及基类源码逐个核对传入的参数名、类型、默认值、绑定属性与回调；优先查项目约定的本地源码目录，本地副本须核实版本匹配，缺少匹配源码时查对应官方 tag。禁止凭记忆沿用 BootstrapBlazor 或其他版本的参数名；技能与示例不能替代本次参数核名。
- 组件参数、原生 HTML attribute 与未匹配属性透传必须区分：不能因编译通过或 DOM 出现同名 attribute 就认定组件已接收参数；涉及按钮类型、复选框绑定等迁移点，须核对组件实际读取、渲染和触发回调的路径，并验证回显、操作与保存后重新加载。
- 遇到「已传参数但行为不生效」，第一步先检索当前版本组件及基类源码确认参数存在且实际生效，再排查绑定、事件与数据链路。浏览器验证前先确认选择器命中实际交互元素，核对元素类型、数量与关键属性，避免查错元素而误判修复无效。
