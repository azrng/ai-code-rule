## 项目 README 维护

- `README.md` 是项目事实入口：写项目是什么、安装、配置、构建、运行与核心用法，面向开发者、使用者与 AI；不复制 `AGENTS.md`（AI 协作规则）、`TASK.md`（活动任务）与专项技术文档的内容，反向亦然
- 新项目缺少 `README.md` 时，在项目具备可描述的实际内容后创建最小可用版本；推荐结构：项目简介、技术栈、项目结构、环境要求、快速开始、使用说明、相关文档，仅有真实内容的章节才保留
- 已有项目缺少 `README.md` 时，发现后提示补充；用户确认完善文档或任务明确包含文档初始化时再创建，不主动生成
- 功能、安装、配置、构建、运行、部署或对外接口发生影响使用者的变化时，同步检查 `README.md`，仅更新实际受影响的章节；内部重构、Bug 修复、注释调整不要求更新，除非原有说明已不准确
- 文档与实现冲突时，以核实后的事实为准并报告差异；技术栈、目录结构可依据代码分析填写，运行命令必须经验证或明确标注「未验证」；不编造功能、依赖版本、命令或验证结果
- 本节约束项目根 `README.md`；包目录等子级 README 按所在子规则的专项文档规范维护
