## AI 交互展示补充

- 本组合含 AI 能力：模型调用、流式订阅与 Prompt 管理的完整规则以 `ai-AGENTS.md` 为准，本节只约束界面落地
- 消息与对话组件（消息列表、气泡、打字机、停止 / 重试按钮）优先沉淀为独立组件，不内嵌在业务页面里
- 模型输出按流式增量渲染：合并分片、节流刷新，禁止每个分片触发全列表重渲
- Markdown 与代码块渲染必须经过安全处理（sanitize / 白名单组件），禁止把未消毒内容直接注入 DOM（如 `innerHTML` / `v-html`）
- 生成中禁用重复提交并提供停止按钮；失败展示可读原因与重试入口
- 页面状态覆盖 loading / streaming / empty / error，与 `design-system.yaml` 的页面状态规范一致
