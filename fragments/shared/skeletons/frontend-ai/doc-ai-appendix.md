## AI 产品交互补充

设计文档涉及 AI 能力时，除常规部分外必须补充：

| 部分 | 内容要求 |
| --- | --- |
| 模型与接入 | Provider / 网关选择、接入方式（托管网关 / 服务端代理 / 直连）、密钥归属说明 |
| 交互闭环 | 用户输入 → 模型 → 流式展示 → 用户确认的完整描述，含中断、失败、重试路径 |
| 流式契约 | 流式事件类型、字段与状态流转（与 `ai-AGENTS.md` 封装层一致） |
| Prompt 关键约束 | 系统提示、输出格式、边界与安全约束 |

- 界面原型必须画出 streaming、失败、中断状态，不只画成功态
- 模型输出驱动的界面动作属于高风险变更，需在设计文档中明确用户确认节点
