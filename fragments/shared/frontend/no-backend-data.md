### 无后端数据口径
- 本项目没有配套的独立后端，数据来源只允许三类：本地静态 / mock 数据、浏览器本地存储（localStorage / IndexedDB）、第三方或远端 API
- 调用第三方 / 远端 API 时，统一走项目的请求封装模块：地址、密钥与环境差异通过环境变量或构建配置注入，禁止把密钥硬编码进客户端代码
- 需要持久化的数据统一通过本地存储封装模块读写，禁止在页面组件里直接操作 localStorage / IndexedDB
- 初始数据来自静态 mock 文件或种子数据模块，数据层保持可替换：后续接入真实服务时只替换数据层实现，不改页面组件
- 所有数据读写保持异步一致性（Promise / async），页面按 `loading` / `empty` / `error` 状态完整处理
