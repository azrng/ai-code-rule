### 服务端授权边界
- 权限校验必须落在服务端入口（事件处理器、应用服务、API 端点、资源读写入口）；前端隐藏按钮、路由保护、客户端缓存的角色信息只改善交互，不构成安全边界。
- 「默认拒绝」必须由框架级全局兜底机制实现（如全局回退授权策略），不靠逐端点挂「需认证」标注——逐点标注属「默认放开、显式收紧」，新增端点漏标即静默匿名；匿名例外端点显式标注放行，整资源（控制器 / 路由组）均无鉴权需求时标注上移到类 / 组级，不逐动作重复挂。
- 不信任客户端提交的角色、权限、用户 ID、资源范围等身份与授权信息；服务端从已认证身份和当前授权数据重新解析并校验。
- 末位管理员保护、内置角色不可删等关键业务约束必须在所有写入入口统一执行，不能只靠前端禁用控件。
