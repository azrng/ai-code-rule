- 读查询默认不包事务：单语句读（含 join / 子查询 / GROUP BY）在 READ COMMITTED 下自带一致快照（PostgreSQL / MySQL 恒成立；SQL Server 需开启 RCSI，默认锁定读下长扫描仍可能撕裂）；需要跨语句一致时优先折进单语句表达，其次靠写侧 CAS + 唯一约束 + 重读复检栅栏。事务级快照（RepeatableRead / Serializable）仅用于「多条语句必须互相一致且不一致会引发错误行为」的场景，隔离级别说不出对应不变量就不包；NEVER 把外部调用（SSO / HTTP / 第三方）圈进读事务，NEVER 把重读栅栏的首读与复检放进同一个快照事务。
