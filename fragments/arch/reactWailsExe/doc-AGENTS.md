## 设计系统文件规范
`design-system.yaml` 是唯一设计系统文件，包含：
- 品牌与产品风格意图
- 语义化颜色 token
- 排版 token
- 间距、圆角、阴影 token
- 布局规则
- Ant Design 主题配置映射
- 页面状态规范
- 组件使用规则
- 明确的 `do / dont` 规则
