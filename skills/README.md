## skills

### 文档与办公

#### docx

Word 文档创建、读取、编辑与分析技能，适用于 `.docx` 文档、报告、模板、批注、修订和格式处理。

GitHub：https://github.com/anthropics/skills/tree/main/skills/docx

#### pdf

PDF 读取、提取、合并、拆分、旋转、水印、创建、表单填写、加解密、图片提取和 OCR 处理。

GitHub：https://github.com/anthropics/skills/tree/main/skills/pdf

#### pptx

PPTX 幻灯片创建、读取、解析、编辑、合并、拆分、模板处理和演讲者备注处理。

GitHub：https://github.com/anthropics/skills/tree/main/skills/pptx

#### xlsx

电子表格处理技能，适用于 `.xlsx`、`.xlsm`、`.csv`、`.tsv` 的读取、编辑、清洗、公式、格式和转换。

GitHub：https://github.com/anthropics/skills/tree/main/skills/xlsx

### 前端、UI 与浏览器

#### frontend-design

创建高质量、差异化的前端界面、页面、组件、海报和 Web 应用，强调可用性与视觉完成度。

GitHub：https://github.com/anthropics/skills/tree/main/skills/frontend-design

#### ui-ux-pro-max

高质量 UI/UX 设计辅助 skill，用于提升界面设计、交互体验和视觉表达。

GitHub：https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

#### webapp-testing

webapp-testing 是一个基于 Playwright 的本地 Web 应用测试工具集，支持前端功能验证、UI 调试、页面截图及浏览器控制台日志采集，遵循“先侦查后执行”的流程。

在线安装：`npx skillsauth add alter123-zz/RaccoonClaw webapp-testing`

#### Agent-browser

浏览器自动化相关 skill，用于在浏览器中打开、导航、检查、截图或测试本地与远程页面。

GitHub：https://github.com/vercel-labs/agent-browser/tree/main/skills/agent-browser

### 联网、搜索与数据处理

#### web-access

真实浏览器与联网访问技能，覆盖搜索、网页抓取、登录态页面操作、动态页面读取和网络交互。

GitHub：https://github.com/eze-is/web-access

#### web-scraper

使用 Python 搜索互联网、抓取网页、提取链接/表格/结构化内容，并可处理 JavaScript 渲染页面。

在线安装：`openclaw skills install web-scraper`

#### tavily-search

基于 Tavily API 的 AI 优化联网搜索，返回适合 Agent 使用的简洁相关结果。

在线安装：`npx -y clawhub@latest install tavily-search`

#### csv-pipeline

处理、转换、分析 CSV、TSV、JSON、JSON Lines 等表格数据，支持过滤、合并、聚合、去重和报告生成。

在线安装：`openclaw skills install csv-pipeline`

#### summarize

通过 summarize CLI 总结 URL、本地文件、PDF、图片、音频和 YouTube 链接。

在线安装：`brew install steipete/tap/summarize`

### 开发、调试与平台协作

#### aspnet-core

ASP.NET Core Web 应用构建、审查、重构与架构设计规则，覆盖 Blazor、Razor Pages、MVC、Minimal APIs、SignalR、gRPC、认证授权、测试、性能与升级。

GitHub：https://github.com/openai/skills/blob/main/skills/.curated/aspnet-core/SKILL.md

#### github

通过 `gh` CLI 操作 GitHub issues、PR、CI runs 和 GitHub API。

在线安装：`npx clawhub@latest install github`

#### systematic-debugging

遇到 bug、测试失败或异常行为时，先执行系统化根因分析，再提出修复方案。

在线安装：`openclaw skills install runesleo-systematic-debugging`

#### pua

高压式问题解决与交付验证风格技能，用于推动 Agent 在失败、返工或质量问题场景下进行更彻底的排查和验证。

GitHub：https://github.com/tanweai/pua

### Agent 能力与工作流

#### skill-creator

创建或更新 Agent skill 的指导技能，覆盖 skill 结构、触发描述、脚本、参考资料、资产与打包校验。

GitHub：https://github.com/anthropics/skills/tree/main/skills/skill-creator

#### find-skills

发现和安装开放 Agent skills 生态中的可用技能，用于查找某类任务是否已有现成 skill。

在线安装：`npx clawhub@latest install find-skills`

#### self-improving-agent

记录错误、用户纠正、外部工具失败、知识过期和最佳实践，用于持续改进 Agent 行为。

GitHub：https://github.com/peterskoett/self-improving-agent

#### brainstorming

在创造性开发前进行需求澄清、方案探索和设计确认，帮助把想法转化为可执行规格。

在线安装：`openclaw skills install tlreal/core-brainstorming`

### 内容、生活与个人效率

#### blog-author

深度调研主题、分步规划博客，并在当前工作目录输出结构化 Markdown 长文，支持多语言写作、来源追踪和可选图片插入。

GitHub：https://github.com/AIDotNet/OpenCowork

#### news-summary

通过可信国际 RSS 源获取和总结新闻，可用于新闻更新、每日简报和世界动态摘要。

在线安装：`npx clawhub@latest install news-summary`

#### tailored-resume-generator

分析岗位描述并生成针对性简历，突出相关经验、技能和成果以提升面试机会。

在线安装：`npx skills i ComposioHQ/awesome-claude-skills/tailored-resume-generator`

#### weather-advisor

智能天气顾问，支持实时天气、未来 7 天预报、穿衣建议和出行活动推荐。

在线安装：`npx skillsauth add alter123-zz/RaccoonClaw weather-advisor`

#### wechat-ui-sender

通过 Windows 微信客户端 UI 自动化发送 Markdown 消息，支持联系人搜索、粘贴发送、重试和审计截图。

在线安装：暂无明确在线来源。
